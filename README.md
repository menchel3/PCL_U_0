PCL-U
=====

Environment
-----------
Create and activate environment:

	conda env create -f environment.yaml
	conda activate PCL-U


Reproduce results
-----------------
Run the IHDP example:

	bash run_ihdp_experiment.sh

The script trains and evaluates the dataset by default.


NMMR experiment
---------------
The `nmmr/` directory contains the self-contained NMMR experiment on the
PCL-U synthetic data. It includes the data, configurations, model, training
code, and an independent environment named `NMMR`.

	cd nmmr
	conda env create -f environment.yaml
	conda activate NMMR
	bash run_all.sh

See [nmmr/README.md](nmmr/README.md) for details.

More details about data and code
--------------------------------

### Data

The IHDP and Jobs datasets are from [Fredjo's website](https://www.fredjo.com/),
and the [Twins dataset](https://github.com/jameszhou-gl/CBRE/tree/master/data).

The `1/2/8-4-4-4` and `s/m/h` synthetic datasets are generated by
[`generate_data.py`](generate_data.py), which implements the synthetic-data
generation process described in the paper.

### Code

The code builds on [CFR](https://github.com/clinicalml/cfrnet),
[DeR-CFR](https://github.com/anpwu/DeR-CFR),
[CBRE](https://github.com/jameszhou-gl/CBRE), and
[CITE](https://github.com/XinshuLI2022/CITE) for fair comparison.
